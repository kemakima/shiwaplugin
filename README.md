# ClothWrinkle（服のしわ）試作 v0.4.1（リアルタイム版）

体を曲げたときに、服（レオタードなど）の縮んだ所へしわを描き足す KKS CharaStudio 用プラグインです。
しわは法線マップ（陰影）として描くので、服の輪郭は変わりません。

## 使い方
1. `KKS_ClothWrinkle.dll` を `BepInEx\plugins` に入れて Studio を起動します。
2. キャラを選び、「アニメ → 現在の状態」の **「服のしわ」** で「しわを付ける」をオンにします。
3. ポーズやアニメーションに合わせて、しわの濃さがリアルタイムに変わります（v0.3.0）。

| 項目 | 内容 |
|---|---|
| 強さ | しわの陰影の濃さ |
| しわの細かさ | 大きいほど折り目の間隔が狭くなる（1〜20、既定 5） |
| 曲げへの反応 | 少しの縮みでも濃いしわになる |
| 小さな縮みを無視 | これ以下の縮み・伸びはしわにしない（体型による歪みを消す） |
| 折り目の鋭さ | 大きいほど細く鋭い折り目 |
| しわ模様 | 模様のパターンを変える |
| リアルタイム更新 | オフにすると止まる。そのときは「今のポーズで更新」で描き直す |
| 今のポーズで更新 | 押すたびに、今のポーズでしわの濃さを計算し直す |
| 今のポーズを基準にする(通常は自動) | 通常は「体型込みの直立姿勢」が自動で基準になる。特定のポーズを基準にしたいときだけオン（シーンには保存されません） |

「服のしわ (対象)」で、トップス・ボトムス・インナー上下・手袋・パンスト・靴下・靴を個別にオン/オフできます（靴は標準でオフ）。

設定はキャラごとにシーン・キャラカードへ保存されます。

## 仕組み（v0.3.0 リアルタイム版）
重い処理は最初に1回だけ行い、毎フレームは「どこがどれだけ縮んでいるか」だけを更新します。

**最初に1回（有効にしたとき・模様のスライダーを動かしたとき）**
1. 横じわの模様を、しわが最大に出た状態で法線マップとして作ります（v0.3.3 から、向き1本だけのしま模様。複数の向きを混ぜると×印に見えたため）。向きは体の長さ方向（胴体・脚は上下、腕は腕のボーンの向き）と直角です。
2. 元の法線マップも同じ形式に変換しておきます。
3. 服のメッシュを UV に展開した形のメッシュを作ります。

**毎フレーム（最大 30 回/秒、服が画面に映っているときだけ）**
1. 服の今の形を取得し（BakeMesh）、元の形と三角形ごとに比べて縮み・伸びの量を求めます。
2. 頂点ごとに平均して「しわの濃さ」にし、UV展開メッシュの頂点色に入れます。
3. GPU で「元の法線」の上に「しわ最大の法線」を頂点の濃さで重ねて、`_NormalMap` の RenderTexture に描きます（専用シェーダーは使いません）。

折り目の位置は固定で、曲げに合わせて濃くなったり消えたりします。

## v0.4.0 の変更
- **基準の自動化**: ボーンの回転だけを直立（バインド）姿勢に戻した形を自動で計算し、基準にします。キャラメイクの体型による服の歪みを拾わないので、立っているだけではしわが出ません。
- **体の軸方向の縮みだけを見る**: 横じわは「上下（腕は腕の向き）に縮んだ所」にだけ出ます。伸びた側や、横から押された所には出ません（「張りじわ」スライダーは廃止）。
- **静止中は計算しない**: 主要な関節（cf_j_*、胸・お尻・スカート・髪などの揺れ物を除く）が動いていなければ計算をスキップします。

## v0.4.1 の変更（手袋対策）
- 元の画像が小さい服（手袋の 512x256 など）は、法線マップを長い辺 1024 まで拡大して描きます（しわのギザギザ対策）。しわの計算解像度も出力に合わせて上げます。
- 腕のしま模様の位置を「肩からの腕の長さ」で決めるようにしました。以前は向きだけで決めていたため、ひじなど向きが変わる所でしまが詰まって波紋のように見えていました。

## 設定ファイル（`BepInEx\config\zuki.kks.clothwrinkle.cfg` または F1）
- `Wrinkle map resolution`（既定 512）: しわを計算する解像度の下限（v0.4.1 から、出力の大きさに合わせて最大 1024 まで自動で上げる）
- `Normal map max size`（既定 1024）: 書き込む法線マップの最大サイズ（v0.4.1 から、元が小さい画像は長い辺 1024 まで拡大）
- `Max updates per second`（既定 30）: リアルタイム更新の最大回数。下げるほど軽い
- `Log strain stats`: オンにすると、更新のたびに服ごとの最大の縮み・伸びと計算時間をログに出します（調整用）

## 制限（試作版）
- 陰影だけなので、横から見た輪郭は平らなままです。
- `_NormalMap` を持つシェーダーのみ対象です（Koikano/main_clothes 系と Az/Standard 系は持っています）。
- 物理演算の布（Cloth コンポーネント付きのスカートなど）は対象外です。
- DirtFX の「泥の立体感」も `_NormalMap` を書き換えるので、同じ服に両方使うと取り合いになります。
- しわは横じわのみです（v0.2 の「横じわに揃える」は廃止）。向きは、胴体と脚は上下方向、腕は腕のボーンの向きを基準にしています。
- 折り目の位置はポーズで動きません（濃さだけが変わります）。
